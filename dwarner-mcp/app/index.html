Umbrel MCP Server

AI agents read the list of tools when they connect. After changing a switch, reconnect the agent (in Claude Code: /mcp, then reconnect) to see the change. A tool that has been switched off stops working immediately.

Connect an AI agent

••••••••••••••••

Agents send the token as Authorization: Bearer <token>. Anyone with the token can use whatever is switched on below. A new token disconnects every agent using the old one.

            sudo xxd -ps -c 1000 ~/umbrel/app-data/lightning/data/lnd/data/chain/bitcoin/mainnet/readonly.macaroon

            Use invoice.macaroon to also create invoices, or admin.macaroon to pay them.
